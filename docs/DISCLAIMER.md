# Disclaimer

**LandslideGuard NER** is a personal learning and portfolio project. It is **not** an official emergency-warning system, a government product, or a validated early-warning tool.

Do not use this app to make safety, evacuation, or emergency decisions. For real hazards, follow guidance from local authorities and official meteorological or disaster-management agencies.

## What this project is allowed to show

- A web demo of how landslide reports could be mapped for Northeast India.
- **Sample data** that is clearly labeled as sample (invented for learning, not real events).
- A link to **NASA’s global landslide nowcast** as an *external* reference, not as a forecast produced by this app.
- An experimental Hugging Face model output based on Sentinel-2 layers. The selected fine-tune uses Italian-region examples and is not validated for Northeast India; its scores are not calibrated probabilities or official warnings.

## What this project must not claim

- It does not forecast a future landslide.
- It does not replace official alerts.
- It does not invent real events or real model results. Mock or sample content is labeled as such.

If anything in the interface is unclear, treat it as a demo only.
