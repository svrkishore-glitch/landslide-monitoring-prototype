# Data and model sources

This file records sources used or linked by the prototype. **No large datasets or model weights are in the repo.**

## Regional weather dashboard

| Source | Status | Fit and limits |
| --- | --- | --- |
| [Open-Meteo Forecast API](https://open-meteo.com/en/docs) | **Live prototype integration**; queried by the FastAPI backend for eight state-capital reference locations | Supplies model-based current conditions and hourly weather forecasts, including precipitation probability and shallow soil moisture. It is weather context, not landslide observations or a validated landslide prediction. Free API access is for non-commercial use; attribution/data are CC BY 4.0. Check current provider terms before commercial use. No API key is required for this prototype. |

Coordinates are fixed representative city points (state capitals), not comprehensive spatial coverage. A single city forecast does not describe all terrain or rainfall within a state. The service is refreshed by the app every 15 minutes, but the upstream weather models update on their own schedule; this is not sensor telemetry. The map colors represent forecast rainfall thresholds only and must not be interpreted as hazard levels.

## Hugging Face image analysis (Phase 3)

| Source | Status | Fit and limits |
| --- | --- | --- |
| [Sciamlab/LFM2.5-VL-450M-landslide-GGUF](https://huggingface.co/Sciamlab/LFM2.5-VL-450M-landslide-GGUF) | **Phase 3 optional local integration**; 430 MB language checkpoint + 182 MB vision projector (about 612 MB total), GGUF, LFM Open License v1.0 | Fine-tuned for landslide assessment from seven Sentinel-2 composite layers, not ordinary photos. The model card reports no hosted Inference Provider, so this prototype calls a local `llama.cpp` server. The fine-tune and expected inputs are not validated for Northeast India. Output is experimental model-generated text/scores, not calibrated probability, event confirmation, or official warning. |
| [Sciamlab/landslide-sentinel2-vlm](https://huggingface.co/datasets/Sciamlab/landslide-sentinel2-vlm) | Optional example input source; image/text dataset on Hugging Face | Examples describe Italian-region Sentinel-2 scenes. Use only to try the interface and label results as out-of-region examples. It is not NER ground truth. |
| [Sciamlab/landslide-prevention-italy](https://huggingface.co/datasets/Sciamlab/landslide-prevention-italy) | Related training dataset | Dataset card describes Italian events, 111 samples (89 train / 22 test), 512×512 Sentinel-2 composites, and annotations generated by a vision-language model. This is a substantial domain and annotation-quality limitation, not an authoritative landslide inventory. |

The input layer order follows the model card: RGB, SWIR, NIR, NDMI, NDVI, BSI, TCT Wetness. Model weights are **not** committed to this repo. The LFM Open License v1.0 has a commercial-use threshold; review the [official license](https://www.liquid.ai/lfm-license) before using the model in a commercial setting. The adapter submits images only to `127.0.0.1:8080` (the locally running llama.cpp service).

## APIs and keys

The weather prototype needs **no API key**. Map tiles come from OpenStreetMap in the browser. The optional Hugging Face inference runs locally. Express and MongoDB are not part of this project.

## What is not in the repo

- Large landslide catalogs
- Satellite archives
- Model checkpoints (downloaded separately by the user, about 612 MB)
- Secrets or `.env` API keys
